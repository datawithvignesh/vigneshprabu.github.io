# vigneshprabu.github.io

Personal portfolio website for Vignesh Prabu — Web Analyst & Developer.

Live at: [vigneshprabu.com](https://vigneshprabu.com)

## About

A single-page portfolio showcasing my work in digital analytics and web development. Built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step.

## Features

- Typewriter animation cycling through roles (Web Analyst, Analytics Engineer, GA4 Specialist, DataLayer Architect)
- Light/dark mode with system preference detection
- Scroll-triggered fade-in animations
- Responsive layout with mobile hamburger nav
- Open Graph and Twitter Card meta tags for link previews

## Sections

- **Hero** — intro with animated role text
- **About** — background and focus areas
- **Skills** — Analytics (GA4, Firebase, Looker Studio), Tag Management (GTM, DataLayer, Server-side GTM), Development (JS, HTML/CSS, Python, SQL), Data & Cloud (BigQuery, Segment, Amplitude, GCP)
- **Projects** — DataLayer Relay, GA4 Migration Toolkit, Firebase App Tracking
- **Contact** — links to email, LinkedIn, and GitHub

## Stack

| Layer | Tech |
|-------|------|
| Markup | HTML5 |
| Styling | CSS custom properties, CSS Grid, Flexbox |
| Scripting | Vanilla JavaScript (IntersectionObserver, matchMedia) |
| Font | Inter (Google Fonts) |
| Hosting | GitHub Pages |
| Domain | Custom domain via CNAME (`vigneshprabu.com`) |
